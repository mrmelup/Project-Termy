# Project-Termy
This project is a personal project that tests my Python ability and helps me learn more about the terminal. Termy is a fake shell that combines Linux and Bash to create an interesting interface for a terminal.

# Goals & Hopes
The goal for this project is for me to master the terminal while also being able to teach someone how a terminal works. It can also encourage other people to develop their own custom shells for fun
